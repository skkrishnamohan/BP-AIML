## How to study

1. Read the module’s **`00-START-HERE.md`** so you know what that week was trying to build.
2. Take **one session file** and read it as a lecture. When you hit a worked example, cover the last line and finish the arithmetic yourself.
3. Answer the checkpoint in your own words before you open the next file.
4. Use the short tables only as the board summary after you have followed the explanation.
